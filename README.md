# Adaptive Building Menu

Adaptive local mod for Oxygen Not Included.

The mod expands the building menu up to `MaxRows` rows and then adds more columns, up to `MaxColumns`, so large modded build categories need much less scrolling.

Build:

```powershell
dotnet build .\AdaptiveBuildingMenu.csproj -c Release
```

The build copies `AdaptiveBuildingMenu.dll` into this directory so the folder can be used directly as a local ONI mod.
